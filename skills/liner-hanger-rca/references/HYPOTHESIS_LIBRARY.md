# Non-exhaustive hypotheses to test, never automatic diagnoses
- Unexpected mechanical loading / drag / string movement / tight hole. Check pickup/slack-off trends vs position, RPM/torque and operator annotations.
- Premature liner hanger slip or liner-top packer engagement: requires mechanism-specific information and independent confirmation, not just a hookload event.
- Hydraulic event or undesired activation path: review pressure vs pump rate, circulation stage, fluid changes, seat/valve arrangement and anti-preset features.
- Pressure restriction or packoff: test with flow response, returns, rate changes and concurrent mechanical loading; alternative sensor error must remain possible.
- Running tool release/engagement anomaly: distinguish intended release command and observed confirmation from inferred behavior.
- Volume/displacement discrepancy: check pump factor, strokes, manual tallies, return balance, pressure evolution and timestamps.
- Incorrect configuration, assembly or procedural execution: compare as-built tally, tool revision, verified checklist and incident details.
- Sensor or timebase error: evaluate calibration, offsets, sampling and missing channels before claiming a mechanical cause.
For each hypothesis: list predicted signatures, supporting evidence, contradictory evidence, missing discriminating tests, and conclusion status.
